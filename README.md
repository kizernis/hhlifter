# HH Auto-Lifter 🚀

Система автоматического обновления резюме на HeadHunter (hh.ru) по расписанию. 
Реализована как микросервисная архитектура с использованием очередей задач и Stealth-автоматизации браузера.

## 🛠 Технологический стек
- **Backend:** Python 3.10, FastAPI (для управления через API)
- **Database:** PostgreSQL (SQLAlchemy 2.0 ORM)
- **Task Queue:** Celery + Redis
- **Automation:** Playwright / Patchright (Asyncio)
- **Infrastructure:** Docker, Docker Compose
- **Security:** Обход систем детекции ботов (Stealth-автоматизация, Fingerprinting)

## 🌟 Ключевые особенности
- **Scout-MassLift Logic:** Двухэтапная архитектура. Сначала "разведчик" проверяет сессию и проходит авторизацию, затем "десант" из параллельных вкладок обрабатывает список резюме в одной сессии (asyncio.gather).
- **Stealth Automation:** Использование Patchright и специфических настроек браузера для минимизации вероятности обнаружения бота.
- **Distributed Architecture:** Бэкенд, воркер и планировщик (Celery Beat) разнесены по отдельным контейнерам.
- **Tracing:** Встроенная система отладки через Playwright Trace Viewer (отчеты сохраняются в папку `/traces`).

## 🚀 Запуск
1. Создайте файл `.env` в котором укажите свои логин/пароль от HH:
```
HH_LOGIN=логин
HH_PASSWORD=пароль
```
2. Запустите систему:
```bash
docker-compose up --build -d
```
3. Управляйте списком резюме через Swagger UI: http://localhost:8000/docs
